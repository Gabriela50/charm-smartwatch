# Criterios de aceptacion
- [ ] La aplicacion inicia sin cerrarse.
- [ ] La navegacion funciona.
- [ ] La entrada digital es visible.
- [ ] La agenda presenta datos o estado vacio.
- [ ] Los eventos demo se identifican claramente.
- [ ] El cambio de idioma funciona.
- [ ] La personalizacion funciona.
- [ ] El asistente responde con servidor disponible.
- [ ] El simulador permite recorrer toda la interfaz.
