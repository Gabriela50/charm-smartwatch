# Arquitectura de CHARM

CHARM es un simulador de smartwatch desarrollado con Kotlin y Jetpack Compose.

## Componentes
- Interfaz adaptada a pantallas circulares.
- Navegación entre módulos del reloj.
- Agenda y eventos demostrativos.
- Acceso a entradas digitales de ejemplo.
- Personalización visual.
- Asistente CHARM IA.

## Integraciones
El asistente puede comunicarse con un servidor Node local.
La agenda puede consultar eventos del calendario cuando existen permisos.

## Alcance
El proyecto se presenta como simulador, no como instalación en un reloj físico.
