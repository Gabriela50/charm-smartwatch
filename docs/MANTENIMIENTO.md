# Mantenimiento de CHARM

## Antes de cada cambio
1. Identificar el componente.
2. Implementar la mejora.
3. Verificar la compilación cuando el entorno esté disponible.
4. Probar la navegación.
5. Revisar los archivos modificados.
6. Crear un commit descriptivo.

## Precauciones
No publicar claves de API ni contraseñas.
No incluir copias temporales o archivos de respaldo.
No presentar datos simulados como eventos reales.
