# Revision docente - CHARM

## Arquitectura
Aplicacion Wear OS con Kotlin y Jetpack Compose.
Interfaz adaptada a pantalla circular.
Servidor local Node para el asistente.

## Funcionalidades
- Navegacion por pantallas.
- Entrada digital de demostracion.
- Agenda y eventos simulados.
- Cambio de idioma espanol e ingles.
- Personalizacion visual.
- Asistente CHARM IA.

## Demostracion
Utilizar el emulador Wear OS.
Mostrar la agenda y distinguir los datos simulados.
Comprobar que el servidor de IA este disponible.
Verificar desplazamiento y navegacion.

## Repositorio
El codigo Android esta en la rama master.
La rama main conserva la version web.
