# Ejecución de CHARM

## Proyecto Android
El código fuente se encuentra en este repositorio.
La interfaz utiliza Kotlin y Jetpack Compose.

## Simulador
Se utiliza un emulador Wear OS para presentar la aplicación.

## Asistente
El servicio local de IA se ejecuta por separado.
Su funcionamiento requiere configuración y conectividad adecuadas.

## Distribución
Antes de entregar una APK se debe comprobar instalación,
navegación y comportamiento en el emulador correspondiente.
