# CHARM Smartwatch

Aplicación de demostración para Wear OS desarrollada con Kotlin y Jetpack Compose.

## Funcionalidades

- Navegación entre pantallas.
- Entrada digital de demostración.
- Agenda y eventos simulados.
- Personalización de idioma y apariencia.
- Asistente conectado a un servidor local.

## Pruebas

Ejecutar: python3 -m unittest discover -s tests -p 'test_*.py' -v

## Presentación

El proyecto Android se presenta mediante un emulador Wear OS. Las funciones dependientes del servidor requieren que esté disponible.
